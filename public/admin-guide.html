🛡️ Руководство администратора / модератора IronAds

Данное руководство предназначено для пользователей с ролью администратор или модератор. Описаны все возможности админ-панели.

🚪 Доступ к админ-панели

  • После входа в систему, в шапке появится кнопка «⚙️ Админ-панель».
  • Админ-панель также доступна по адресу /admin.html (требуется авторизация и права).

👥 Управление пользователями (вкладка «Пользователи»)

  • Поиск и фильтры: по имени, email, телефону, роли, статусу блокировки, включая удалённых.
  • Редактирование (кнопка ✏️): изменить имя, email, телефон, роль. Также можно задать/изменить контрольный вопрос и ответ (полезно для старых аккаунтов).
  • Сброс пароля – генерируется новый пароль, который отображается на экране (сообщите пользователю).
  • Блокировка/разблокировка – заблокированный пользователь не может входить и размещать объявления.
  • Удаление (мягкое) – пользователь скрывается. Восстановление возможно в течение 90 дней.
  • Создание пользователя – вручную (логин, пароль, телефон, email, роль).
  • Экспорт/импорт CSV – массовое добавление пользователей или выгрузка списка.

📦 Управление объявлениями (вкладка «Объявления»)

  • Поиск по названию, фильтр по статусу (активные, архивные, заблокированные), поиск по ID пользователя, опция показа удалённых.
  • Действия над объявлением:
    • Просмотр – открыть на сайте.
    • Заблокировать – с указанием причины. Объявление скрывается для всех (кроме модераторов).
    • Разблокировать – возвращает активный статус.
    • Удалить (мягкое) – скрывает объявление, можно восстановить в течение 30 дней.
    • Восстановить – возвращает удалённое объявление.

🚨 Жалобы (вкладка «Жалобы»)

  • Список жалоб от пользователей на объявления или других пользователей.
  • Для каждой жалобы:
    • Принять – объявление блокируется, либо пользователь блокируется. Жалоба получает статус «Рассмотрена».
    • Отклонить – жалоба закрывается без последствий.
    • Просмотреть – открыть объявление в новой вкладке.

📂 Управление категориями (вкладка «Категории (дерево)»)

  • Иерархическое дерево: группы → подгруппы → категории.
  • Кнопки: добавить корневую группу, добавить подкатегорию, редактировать (название, slug, иконку, родителя, порядок, активность), скрыть/восстановить.
  • Slug должен быть уникальным, содержать латиницу, цифры, дефисы.

🏙️ Управление городами (вкладка «Города»)

  • Иерархия: регионы → города. Можно добавлять, редактировать, удалять регионы и города.
  • Удаление региона удаляет все его города. Город нельзя удалить, если к нему привязаны объявления.
  • Для городов можно установить флаг «Популярный» и порядок сортировки.

⚙️ Системные настройки (вкладка «Настройки»)

  • hCaptcha – включение/выключение капчи, публичный и секретный ключи (получаются на сайте hCaptcha).
  • Цены и периоды – стоимость размещения, продления, автопилота; сроки действия. Все значения редактируются через интерфейс.
  • После изменения параметров обязательно нажмите «Сохранить всё».
  • Кнопка «↺ Сбросить цены к значениям по умолчанию» – восстанавливает 200, 150, 100.

📨 Обращения с сайта (вкладка «Обращения с сайта»)

  • Сообщения, отправленные через форму «Связаться с поддержкой» (доступна без авторизации).
  • Для каждого сообщения видны: дата, имя (если указано), email, тема, текст, IP, статус (новое/прочитано).
  • Действия: отметить прочитанным, ответить по email (откроется почтовый клиент).

🛎️ Обращения в техподдержку (тикеты)

  • Тикеты, созданные авторизованными пользователями через раздел «Поддержка» в меню.
  • Администратор может отвечать на тикеты, менять статус (открыто, в обработке, закрыто), создавать отдельный чат с пользователем.
  • Количество непрочитанных сообщений отображается бейджем на вкладке.

📜 Журнал действий (аудит)

  • Фиксируются все важные действия администраторов (блокировки, смена ролей, удаление, изменение настроек и т.д.).
  • Доступны фильтры по дате, администратору, типу действия.
  • Используется для контроля и расследования инцидентов.

🔧 Мониторинг и восстановление (системное)

  • На сервере работает процесс monitor-realtime, который проверяет доступность сайта каждые 5 секунд.
  • При двух последовательных сбоях он автоматически перезапускает туннель xtunnel и отправляет email-уведомление.
  • После восстановления также приходит уведомление с указанием времени простоя.
  • При трёх перезапусках подряд – критическое уведомление (требуется ручное вмешательство).
⚠️ Внимание! Действия в админ-панели (особенно удаление, блокировка, смена ролей) необратимы без возможности отката. Всегда подтверждайте ответственные операции и делайте резервные копии.

📌 Дополнительные рекомендации

  • Резервное копирование – регулярно запускайте скрипт backup_simple.bat (создаёт архив проекта в папке C:\Yandex.Disk\IronMarket_Backups).
  • Обновление версии – после замены статических файлов увеличьте версию кэша в sw.js (например, IronAds-v5).
  • Логи сервера – при ошибках смотрите логи через pm2 logs ironads --lines 50.
  • Тестирование – любые изменения сначала проверяйте на локальной копии.
